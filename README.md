# Rock, Paper, Scissors

A simple browser-based Rock, Paper, Scissors game built with vanilla JavaScript.
Play a best-of-5 match against the computer using prompt() and alert() for input
and output.

## How It Works

- The computer randomly picks Rock, Paper, or Scissors.
- The player is prompted to enter their choice each round.
- After 5 rounds, the final scores are shown along with the overall winner.

## Features

- Randomized computer choice
- Case-insensitive, trimmed player input
- Round-by-round results via alerts
- Score tracking across 5 rounds
- Final match result (win, lose, or tie)
