# Rock, Paper, Scissors

A minimalist, dark-themed Rock, Paper, Scissors game built using **HTML, CSS, and Vanilla JavaScript**. Challenge the computer in a first-to-5 match with an interactive interface, real-time score tracking, and dynamic game results.

## Live Demo

**[Play Rock, Paper, Scissors](https://lemon7h3chick.github.io/rock-paper-scissors/)**

## Features

- **Interactive Gameplay** – Select Rock, Paper, or Scissors by clicking your preferred card.
- **Computer Opponent** – The computer randomly generates its choice every round.
- **Real-Time Scoreboard** – Keep track of both player and computer scores.
- **First-to-5 System** – The first player to reach 5 points wins the match.
- **Dynamic Game Results** – Instantly displays whether you won, lost, or tied each round.
- **Visual Feedback** – Highlights selected cards and displays the computer's choice.
- **Replay Functionality** – Restart the game after a match ends.
- **Minimalist Dark UI** – A clean, modern interface with a dark aesthetic.


### 2. Navigate to the project folder

```bash

```

### 3. Run the game

Open `index.html` in your preferred web browser.

No additional dependencies or installations are required.

## Game Rules

The game follows the classic Rock, Paper, Scissors rules:

- **Rock** beats Scissors.
- **Paper** beats Rock.
- **Scissors** beats Paper.
- Choosing the same option results in a tie.

Each win earns one point. Ties do not award points. The first to reach 5 points wins the match.
